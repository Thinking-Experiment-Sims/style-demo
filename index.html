Discovery Prompts

1) Run with no gravity to build a reference model

Disable gravity and trails, then observe constant-velocity motion.

Question: What net force acts on each particle? What does Newton's 1st Law predict?

2) Enable gravity and observe the effect

Turn gravity ON. Watch how vertical velocity changes while horizontal stays constant.

Question: Which component of velocity is affected by gravity? Why?

3) Compare kinetic energy across speed settings

Try speed multipliers of 1×, 2×, and 3×. Note the Avg Speed readout.

Question: If speed doubles, by what factor does KE change? (KE = ½mv²)

4) Investigate the Chaos preset

Apply the Chaos preset and watch collision frequency.

Question: How does particle density affect the collision rate?

Physics Model Used Here

Each particle obeys Newton's Laws with elastic wall collisions.

When gravity is enabled, a constant downward acceleration of g = 9.8 m/s² is applied each frame. Trails show velocity history, not position.

Color encodes speed — blue = slow, cyan = medium, orange = fast — when "Color by speed" is enabled.

All values are scaled for visual clarity, not real-world units.
