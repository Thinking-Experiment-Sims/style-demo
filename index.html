🔬 Lorem Physics — Help

What is this?

This is a style reference demo for The Thinking Experiment simulation design system. Every UI component you see here is available via sim-core.css.

Components shown

  • Header with action buttons
  • Left controls panel — sliders, toggles, buttons
  • Canvas container with HUD overlay
  • Viz toolbar with dropdown presets
  • Bidirectional slider
  • Modals (this one) and quiz
  • Footer

Keyboard shortcuts

  • Space — Pause / Resume
  • R — Reset particles
